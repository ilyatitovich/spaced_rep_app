# SpacedRepApp marketing site

Static Astro site: home, blog, and shared-card decks.

```bash
pnpm --filter spaced_rep_marketing dev
```

- Dev: http://localhost:4321
- App CTA URL: `PUBLIC_APP_URL` (see `.env.example`)
- Brand name: `@spaced-rep/brand`

Deploy as a separate Vercel project with Root Directory `apps/marketing` — see [docs/deploy.md](../../docs/deploy.md).
